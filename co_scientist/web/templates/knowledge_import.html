PACKAGE CONTENTS

ZIP 里放什么？

这些资料共同构成系统的育种知识基础。每个批次按需上传，系统会自动与现有知识合并。

  • CSV
    种质资源材料、ID、性状、可获得性、来源
  • JSON
    作物知识图谱材料、性状、基因/QTL、标记、环境和关系
  • MD/TXT
    证据资料文献摘要、实验记录、材料确认、专家意见
  • CSV
    标记 / QTL检测方法、验证状态、关联材料和风险
  • CSV
    表型协议测定方法、环境、重复设计和推进阈值
  • CSV
    田间试验环境、材料、表型、基因型和试验结论
格式和填写规则

请优先使用下载的标准模板；文献和实验资料请整理为 `.md` 或 `.txt` 文件，PDF 请先整理成证据资料。

暂时没有某类数据时，不需要创建对应文件或 manifest 条目；系统会把该类别视为空增量，并保留旧知识。

整个 ZIP 如果没有任何有效记录会被拒绝，避免空批次误触发审核和版本更新。

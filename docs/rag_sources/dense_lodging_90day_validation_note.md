## Observation Summary

A 90-day window is realistic for project start-up tasks such as seed-source
confirmation, parent identity checks, CAPS marker protocol recovery, parent
polymorphism testing, and first crossing setup. It is not realistic for full
BC2F2 or F3 dense-planting lodging phenotype validation under a standard field
cycle. The first decisive breeding evidence should be framed as marker and
crossing feasibility, not completed field deployment.

# Seita.5G404900 qPH5-1 STARP Marker Literature Note

## Source Identity

- Source type: literature note
- Title: Identification and validation of genetic loci governing plant height in foxtail millet
- Authors/year: BMC Plant Biology, 2025
- URL/DOI: https://doi.org/10.1186/s12870-025-06180-0
- Crop/species: foxtail millet (Setaria italica)
- Main trait: plant height
- Relevant germplasm/materials: 263A, Chuang 29, Ai 88, Jingu 28
- Relevant genes/QTL/markers: qPH5-1, Seita.5G404900, GA20oxSTARP-1

## Evidence Summary

The study identified qPH5-1 as a major plant-height QTL and reported
Seita.5G404900 as a GA20 oxidase gene involved in foxtail millet plant height.
It also reported a STARP marker named GA20oxSTARP-1 for molecular-marker-assisted
selection at the Seita.5G404900/qPH5-1 locus.

## Breeding-Relevant Claims Supported

- Seita.5G404900/qPH5-1 is not only a mapping observation from the 263A x Chuang
  29 work; later literature also treats the locus as a validated plant-height
  target.
- GA20oxSTARP-1 provides an alternative marker direction if the Si5G404900C CAPS
  assay is hard to replicate locally.
- This supports marker-development fallback planning, but not immediate use in
  Jingu 21 or Zhangza 13 without parent polymorphism validation.

## Evidence Boundary

- This note does not replace the Si5G404900C CAPS protocol.
- This note does not prove GA20oxSTARP-1 is polymorphic in Jingu 21 or Zhangza
  13.
- This note does not prove lodging resistance or yield neutrality after
  introgression into elite backgrounds.
- Must verify before use: marker sequence/protocol details, parent polymorphism,
  genotype class interpretation, and association with plant height in the target
  recurrent backgrounds.

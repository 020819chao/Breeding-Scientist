# Seita.5G404900 CAPS Marker Protocol Note

## Marker Identity

- Source type: marker/protocol note
- Marker name: Seita.5G404900 CAPS marker
- Marker assay name in paper: Si5G404900C
- Marker type: CAPS
- Target gene/QTL/region: Seita.5G404900, GA20 oxidase plant-height locus
- Crop/species: foxtail millet (Setaria italica)
- Source URL/DOI/protocol ID: https://doi.org/10.1016/j.cj.2022.09.003; full-text PDF copy consulted at https://www.researchgate.net/publication/365732201_Construction_of_a_genetic_linkage_map_and_QTL_mapping_of_the_agronomic_traits_in_Foxtail_millet_Setaria_italica

## Biological Target

- Target allele/haplotype: frameshift deletion at Seita.5G404900 reported in
  263A.
- Expected phenotype association: semi-dwarf plant architecture.
- Validated populations/backgrounds: published F2 populations involving 263A
  and Chuang 29; marker genotype in the paper differentiated 263A and Chuang 29.
- Unvalidated backgrounds: Jingu 21, Zhangza 13, BC1F1, BC2F2, and local elite
  breeding backgrounds.

## Assay Details

- Primer forward: GCTGACCGGCTGATTGTGTTCG.
- Primer reverse: CTCGCGCGGGCACAGGAAG.
- Restriction enzyme/probe/platform: ScrF I CAPS digestion.
- PCR conditions: not fully specified in the local note; recover the paper or
  lab protocol before ordering and running the assay.
- Expected genotype classes from the published 263A/Chuang 29 assay: 263A was
  reported with a 146 bp band after ScrF I digestion; Chuang 29 was reported
  with 83 bp and 64 bp fragments.
- Controls required: 263A as expected semi-dwarf donor control; Chuang 29 or a
  confirmed wild-type line as tall control; no-template control; F1/heterozygote
  control if available. Jingu 21 and Zhangza 13 must be tested as local
  recurrent-parent controls before selection.

## Breeding Use

- Foreground selection stage: parent confirmation, F1/BC1F1 carrier checking,
  BC2F2 homozygote selection after local protocol validation.
- Background selection compatibility: compatible in principle, but not sufficient
  to estimate recurrent-parent genome recovery.
- Throughput estimate: unknown until the local PCR/enzyme workflow is set.
- Cost/burden estimate: likely low to medium if the CAPS assay is robust, but
  unknown without local validation.

## Evidence Boundary

- This protocol note supports using the published Si5G404900C CAPS assay as a
  candidate marker workflow.
- This protocol note does not prove local assay readiness, marker polymorphism in
  Jingu 21/Zhangza 13, or phenotypic effect in BC lines.
- Must verify before use: primer synthesis/order identity, PCR conditions,
  ScrF I digestion quality, parent polymorphism in 263A/Jingu 21/Zhangza 13,
  expected heterozygote pattern, and at least a small Sanger check if banding is
  ambiguous.

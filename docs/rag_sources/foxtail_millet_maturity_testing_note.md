# Foxtail Millet Maturity Testing Note

This is a seed note for system testing. It supports short-season adaptation and
flowering-window workflows.

Breeding target: improve early maturity and short-season adaptation in foxtail
millet without losing too much yield.

Suggested evidence chain:

- Candidate donor pool: early maturing donor pool.
- Candidate recurrent parents: local recurrent parents.
- Candidate marker route: maturity-window marker clue.
- Phenotyping route: short-season adaptation nursery with two sowing dates.
- Key traits: days to heading, days to maturity, plant height, panicle traits,
  yield, and flowering overlap.

Required local validation:

- Confirm donor and recurrent parents can flower in a synchronized crossing
  window.
- Check whether early maturity reduces biomass or plot yield.
- Use marker clues only after parental contrast is confirmed.

Risk notes:

- Photoperiod and sowing-date effects can dominate marker signal.
- Too-early maturity may reduce yield potential under favorable environments.

# SiNF-YC2 Supplementary Evidence Note

## Source Identity

- Source type: local caution note
- Crop/species: foxtail millet (Setaria italica)
- Main trait: lodging architecture under dense planting
- Relevant genes/QTL/markers: SiNF-YC2; Seita.5G404900 CAPS marker

## Evidence Summary

In foxtail millet, SiNF-YC2-related architecture and CAPS marker screening should
be validated under dense planting and multi-environment field trials before
being treated as a stable lodging-resistance breeding route.

## Breeding-Relevant Claims Supported

- SiNF-YC2 should be treated as supplementary local evidence unless stronger
  source-backed evidence is added.
- SiNF-YC2 should not displace the Seita.5G404900/CAPS route as the main
  selection target without direct validation.

## Evidence Boundary

- This note does not prove a causal relationship between SiNF-YC2 and lodging
  resistance.
- This note does not prove interaction between SiNF-YC2 and Seita.5G404900.
- Use this note to add caution and validation requirements, not to justify a
  primary breeding route.

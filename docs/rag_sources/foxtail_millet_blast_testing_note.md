# Foxtail Millet Blast Testing Note

This is a seed note for system testing. It provides a local evidence-card style
example for blast resistance workflows.

Breeding target: improve blast resistance and general disease resistance in
foxtail millet while preserving acceptable agronomic performance.

Suggested evidence chain:

- Candidate donor pool: resistant donor note.
- Candidate susceptible check: susceptible local check.
- Candidate marker route: Blast-R screening marker set.
- Phenotyping route: replicated disease screening nursery with susceptible
  spreader rows.
- Key traits: leaf blast score, neck blast score, infection type, plant stage,
  and yield loss.

Required local validation:

- Confirm pathogen pressure and avoid nursery escape.
- Validate marker transferability in local parents.
- Compare candidate lines against resistant and susceptible checks.

Risk notes:

- Pathogen race specificity can make a resistance clue fail across locations.
- Uneven inoculum pressure can create false positive resistant calls.

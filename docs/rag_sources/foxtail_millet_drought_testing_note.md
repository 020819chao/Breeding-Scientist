# Foxtail Millet Drought Testing Note

This is a seed note for system testing. It should be treated as a local
planning clue, not as completed scientific proof.

Breeding target: improve drought tolerance and stay-green performance in
foxtail millet under a managed water-stress nursery.

Suggested evidence chain:

- Candidate donor pool: drought tolerant donor pool.
- Candidate recurrent parents: local elite recurrent parents.
- Candidate marker route: SiDREB2-like drought response route.
- Phenotyping route: irrigated control plus managed drought block.
- Key traits: emergence, canopy temperature, stay-green score, leaf rolling,
  biomass, grain yield, and recovery after rewatering.

Required local validation:

- Confirm seed availability for donor and recurrent parents.
- Confirm local parental genotype contrast before treating the marker route as
  selectable.
- Run drought and irrigated control blocks together to detect yield penalties.

Risk notes:

- Drought response is environment-sensitive.
- Soil heterogeneity and stress timing can dominate the observed phenotype.
- Stay-green improvement should not be accepted if irrigated yield drops
  sharply.
